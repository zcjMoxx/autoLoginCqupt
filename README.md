## cqupt校园网自动登录软件

#### 软件用途

该软件主要用于自动登录cqupt校园网，免去了繁琐的手动登录，为离校后网络断连，多设备无法同时连接网络提供解决方案。

#### 研发缘由

由于同一账号在某设备登录授权后，即使不被其他设备挤下线，网络也会在约7天后自动断连，需重新登录验证，这严重影响了实验进程。

众所不周知：机器休息，人学习；机器学习，人休息。科研人必须密切关注每一次迭代的性能抖动，实时评估实验结果。然而，生物体的脆弱机制，如睡眠、吃饭，以及不可抗力的假期，常常使我们被迫离开科研圣地，打断这一神圣进程。我们要求代码在无人值守的情况下持续运行，如同信徒守夜。

于是，远程连接成为刚需。它让我们即使身在千里之外，也能如临现场般监控实验进展，仿佛灵魂出窍，守在服务器旁。但！3G网络的会话有效期限制，如一道天堑，阻断了这场人码合一的美梦。每7天一次的断网，如同命运之手的拨钟，冷酷无情。

于是，本软件应运而生。它将在网络断连的瞬间苏醒，凭预设账号自动登录校园网，保证远程会话正常运行，防止因网络中断而导致科研人茶饭不思、魂不守舍、实验流产。它不是工具，它是科研人的电子续命丹，是代码世界的守夜人，是实验进程的最后一道防线。

最后，由于3G网络的鸡贼设定，平板由于PC端竟然同属于一种设备类型，而手机端由于校园流量而根本不需要连接，这严重浪费了物尽其用的勤俭精神，本软件可以自选设备模拟登录，让狗窝电竞的你也能维持实验的运行。

最后，由于3G网络的鸡贼设定，平板和PC竟被归为同一设备类型，手机又因流量充足不屑搭理3G网络，显得鸡肋。这种隐形消耗，让从小被培育要勤俭节约的花朵们，怒火中烧。因此，本软件开发，支持自选设备模拟登录，让窝在宿舍开电竞的你，也能稳稳吊住实验那口气。

#### 使用手册

第一次运行软件时，会弹出配置提示，按照指示手动填写账号、密码、运营商、UA并保存，后续打开软件会自动根据默认配置去登录网络。

点击“Start”启动软件，开始自动检测网络，发现断连后会尝试重新登陆。点击“Stop”会停止监控，软件不再运行。

当出现错误时，会弹出日志展示，连续出现错误达到一定次数，会展示全屏警告界面，同时软件自动切换为“Stop”状态。

可以手动清除日志文件，文件体积达到一定大小也会自动清除。可以在Settings里更改默认配置文件。

软件运行时，毎一定时间监控一次网络连接，发现网络断连会有错误提示并弹出日志，开始尝试重连，重连间隔随着次数增加而有所延长，直到重连成功或者失败触发警告界面。
